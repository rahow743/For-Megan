Decision Tree Model for Customer Churn
========================================

Relevant steps used to construct the model:
1. Load the processed feature matrix and churn target from Question 1.
2. Split the data into training and test sets using stratified sampling.
3. Fit an unconstrained baseline tree to check how much a fully grown tree overfits.
4. Tune the decision tree hyperparameters with 5-fold cross-validation.
5. Limit model complexity using max_depth, min_samples_split, min_samples_leaf, and ccp_alpha pruning.
6. Choose a balanced model from the near-best CV candidates while preferring enough depth to interpret the tree.
7. Interpret the final trained model using the plotted tree and feature importances.

Efforts used to prevent overfitting and underfitting:
- Used a stratified train/test split to evaluate the model on unseen data.
- Compared a baseline unconstrained tree against a tuned regularized tree.
- Tuned max_depth to stop the tree from growing too deep.
- Tuned min_samples_split and min_samples_leaf to avoid very small unstable splits.
- Tuned ccp_alpha to apply post-pruning and remove weak branches.
- Used 5-fold cross-validation and a complexity curve to balance bias and variance.
- Selected the final model from the near-best CV candidates using a balance of validation score, depth, and generalization gap.
